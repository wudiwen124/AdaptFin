# Streamlit UI 端到端手测清单

前置：`python -m streamlit run app/ui/streamlit_app.py`，`.env` 已配置 chat + embed key。

1. 首页能显示“投顾助手控制台”，侧栏出现用户选择下拉（含历史用户 / ➕ 新用户）。
2. 新用户完成 10 题风险测评，结果卡片显示等级/约束，测评历史追加一条。
3. 说“我买了100股510300，偏好红利低波”，侧栏持仓表出现 510300；再次测评历史不丢。
4. 说“贵州茅台现在怎么样”→ 有研究结论与工具轨迹。
5. 追问“它现在多少钱”→ 直接出行情（不反问），说明指代消解生效。
6. 换说法问“低波动高分红的方向”→ 命中记忆（用户记忆区出现相关偏好）。
7. 切回老用户下拉选择旧 ID → 画像/持仓/历史恢复，可继续对话。
8. 数据管理：删除单个用户后，下拉中消失、checkpoint 线程清理；清空所有用户后回到空状态。
9. 所有回答都带“不构成投资建议”免责；无标的时提示需要代码/名称而不是硬编。
10. 重启 Streamlit 后再选同一用户，画像仍在（长期记忆）；对话上下文从 checkpoint 恢复。
