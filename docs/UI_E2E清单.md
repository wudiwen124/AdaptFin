# Streamlit 页面测试清单

启动页面：

```bash
python -m streamlit run app/ui/streamlit_app.py
```

测试时需要配置可用的聊天模型；语义记忆测试还需要 embedding 配置。

## 基础检查

1. 页面标题为 AdaptFin，右上角不显示 Streamlit Deploy 按钮。
2. 侧栏可以切换已有用户，也可以新建用户。
3. 风险测评能够展开，10 道题和选项都可见。
4. 完成测评后显示风险等级和仓位约束，测评历史增加一条记录。
5. 重新开始测评时可以取消，取消后旧画像仍然有效。

## 对话和数据

1. 输入“贵州茅台现在怎么样”，页面先显示用户消息和思考状态，再显示回答。
2. 追问“它现在多少钱”，系统能识别前文标的，不需要再次输入代码。
3. 输入“你好”，得到普通对话回答，不出现风险测评模板。
4. 输入“我买了 100 股 510300，偏好红利低波”，回答结束后侧栏持仓自动更新。
5. 重启页面后选择同一用户，画像、持仓和历史记录仍然存在。
6. 换一种说法询问之前保存的偏好，记忆区能看到相关记录。

## 数据管理

1. 删除单个用户后，用户选择列表中不再出现该用户。
2. 删除前有确认步骤，删除后相关画像和会话数据被清理。
3. 清空所有用户后，页面回到空用户状态。
4. 金融回答包含风险提示；普通闲聊不强行套用投资分析。

## 自动化检查

页面核心链路的离线检查：

```bash
python scripts/ui_e2e_smoke.py
```

该脚本只验证数据和交互逻辑，不替代浏览器中的样式检查。修改页面布局后仍需人工检查窄屏、长文本和折叠区域的显示效果。
