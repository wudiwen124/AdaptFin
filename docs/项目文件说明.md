# 项目文件说明（全量）

> 按“板块 → 文件 → 一句话职责”组织，说明每个文件负责什么。
> 不含 `__pycache__`、`data/*.db`、`results/`（运行产物）等生成物。

---

## 1. 根目录与工程配置

| 文件 | 职责 |
|---|---|
| `pyproject.toml` | 包元数据与依赖分组：核心（pydantic/langgraph/httpx…）、`data`（akshare/tushare）、`server`（fastapi/uvicorn）、`ui`（streamlit）、`dev`（pytest） |
| `README.md` | 项目入口：进度、快速开始、文档链接 |
| `.gitignore` | 忽略 .env、缓存、运行时 db 等 |
| `.env.example` | LLM key / 数据源 / 模型名的配置模板（不包含真实密钥） |
| `.env` | 本地真实配置（LLM key、模型、数据源），已被 gitignore |
| `Dockerfile` | 容器镜像：python:3.12-slim + `[server,data]`，uvicorn 8001 |
| `docker-compose.yml` | 容器编排：端口 8001、.env 注入、data 卷 |
| `.dockerignore` | 构建时排除测试/文档/运行时文件 |
| `.github/workflows/ci.yml` | GitHub Actions：Python 3.11/3.12 compile + pytest |

## 3. 配置（src/advisor/config.py）

| 文件 | 职责 |
|---|---|
| `src/advisor/config.py` | Settings 模型：Data/Model/Store/Risk 配置；YAML 加载 + `ADVISOR_*`/`LLM_*` 环境变量覆盖 |
| `configs/settings.yaml` | 默认配置：数据源优先级、模型名、db 路径、审计轮数 |

## 4. 领域模型（src/advisor/schemas/）

| 文件 | 职责 |
|---|---|
| `schemas/__init__.py` | 统一导出所有 pydantic 模型 |
| `schemas/common.py` | Symbol（6 位代码→交易所/品种）、Market、Period、代码解析规则 |
| `schemas/market.py` | 行情/财务/估值/公司概况/新闻的数据模型 + SourceMeta（来源/时间/降级标记） |
| `schemas/research.py` | Claim 四分类（FACT/CALCULATION/INFERENCE/CONDITIONAL）、ResearchReport、EvidenceRecord（工具原始证据） |
| `schemas/risk.py` | 10 题问卷、C1~C5 等级、仓位约束、RiskProfile、QUESTIONNAIRE |
| `schemas/user.py` | UserProfile / Holding（数量可未知）等长期画像模型 |

## 5. 数据源层（src/advisor/datasources/）

| 文件 | 职责 |
|---|---|
| `datasources/__init__.py` | DataSourceRouter（缓存/重试/降级/来源链回退）、Registry、build_default_router |
| `datasources/base.py` | 数据源接口协议 + DataNotSupported / DataSourceUnavailable 异常体系 |
| `datasources/cache.py` | 线程安全 TTL 缓存与 cache_key |
| `datasources/demo.py` | 确定性演示数据源：行情/K线/财务/估值/新闻，永不联网 |
| `datasources/akshare_source.py` | akshare 适配器：实时行情、日 K、动态估值（延迟导入、字段防御） |
| `datasources/baostock_source.py` | BaoStock 适配器：历史日/周/月 K（无实时），线程级登录 |
| `datasources/tushare_source.py` | Tushare Pro 适配器：日 K/估值（需 TUSHARE_TOKEN，可选） |

## 6. LLM 层（src/advisor/llm/）

| 文件 | 职责 |
|---|---|
| `llm/client.py` | ModelGateway：OpenAI 兼容 chat、router/deep 分档、超时重试、429/1305 备用模型链 |
| `llm/text.py` | 消息文本/工具调用提取、容错 JSON 解析（兼容代码块包裹） |
| `llm/fake_gateway.py` | 离线 Fake LLM：路由/行情 tool_call/分析师/Advisor/消解/偏好抽取分支，供测试与评测 |

## 7. 编排层（src/advisor/graph/）

| 文件 | 职责 |
|---|---|
| `graph/state.py` | AssistantState：消息、意图、画像、并行结果、证据、问卷进度、turn 级 RESET、实体注册表 |
| `graph/builder.py` | LangGraph 主图编译：节点注册、条件路由、SqliteSaver 持久 checkpointer（msgpack 白名单） |
| `graph/nodes/text.py` | BaseMessage/dict 消息兼容工具（role/content/最近用户文本） |
| `graph/nodes/agent.py` | 通用工具循环（bounded ReAct）：调用 → 观察 → 记录 EvidenceRecord |
| `graph/nodes/supervisor.py` | 路由 + 名称解析 + 实体/指代消解 + 画像加载 + 用户记忆组装 + 每轮清理 |
| `graph/nodes/market.py` | Market Agent：只取行情，不评价 |
| `graph/nodes/research.py` | Research：Send 多标的 fan-out + 每标的三分析师并行 + fan-in |
| `graph/nodes/risk.py` | Risk Agent：问卷查询/首次/重做/取消，评分纯规则 |
| `graph/nodes/advisor.py` | Advisor：风险画像 + 用户记忆 + 最近对话 + 证据区 → 结构化参考意见 |
| `graph/nodes/auditor.py` | Auditor：免责/指令性表述/小数出处/日期 PIT 检查 + 有界回修 |
| `graph/nodes/memory.py` | Memory Writer：风险落库（risk_dirty）、持仓/偏好抽取、assistant 回答写回会话 |
| `graph/nodes/extract.py` | 规则抽取（买/卖/偏好句式）+ LLM 偏好抽取（低置信度丢弃） |
| `graph/nodes/__init__.py` | 节点统一导出 |
