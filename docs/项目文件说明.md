# 项目文件说明

下面对应仓库中的主要目录，帮助接手的人快速找到入口。缓存、数据库和评测运行产物没有展开。

## 根目录

| 文件 | 用途 |
|---|---|
| `pyproject.toml` | 打包信息与依赖分组，包括基础、数据、服务、UI 和测试依赖 |
| `README.md` | 项目入口、运行方式和当前验证结果 |
| `.env.example` | 环境变量示例，不包含真实密钥 |
| `.env` | 本地运行配置，已被 Git 忽略 |
| `Dockerfile` | 服务镜像，默认启动 8001 端口 |
| `docker-compose.yml` | 容器端口、环境文件和数据目录映射 |
| `.dockerignore` | 构建镜像时排除测试、文档和本地产物 |
| `启动AdaptFin.bat` | Windows 启动脚本，打开 Streamlit 页面 |
| `.github/workflows/ci.yml` | Python 3.11/3.12 的 CI 检查 |

## 配置

`src/advisor/config.py` 负责读取 `configs/settings.yaml` 和环境变量。环境变量优先级更高，使用 `ADVISOR_*` 和 `LLM_*` 前缀。数据源优先级、模型名、数据库路径和审计轮次都在 `configs/settings.yaml` 中给出默认值。

## 领域模型

`src/advisor/schemas/` 中定义了各模块共用的数据结构：

- `common.py`：证券代码、交易所、品种和行情周期。
- `market.py`：行情、财务、估值、公司概况、新闻及数据来源信息。
- `research.py`：研究结论、证据分类和工具调用记录。
- `risk.py`：10 题风险问卷、C1-C5 等级和仓位约束。
- `user.py`：用户画像与持仓。

各层通过模型传递数据，避免把来源不明的字典一直传到生成节点。

## 数据源

`src/advisor/datasources/` 维护数据源适配器：

- `base.py`：接口协议和异常类型。
- `__init__.py`：数据源注册、路由、缓存、重试和降级。
- `cache.py`：线程安全的 TTL 缓存。
- `demo.py`：离线演示数据，数值稳定，适合测试。
- `akshare_source.py`：实时行情、K 线、估值、财务和东方财富公告。
- `baostock_source.py`：历史日线、周线和月线。
- `tushare_source.py`：可选的 Tushare Pro 数据源。

`DataSourceRouter` 会按配置顺序尝试数据源。接口不支持当前数据类型时继续向下回退，网络异常则按策略重试，最终仍失败时使用 demo 数据并标记降级。

## 模型网关

`src/advisor/llm/` 只负责模型调用，不包含业务流程：

- `client.py`：OpenAI 兼容接口，router/deep 模型分档，超时、重试和备用模型处理。
- `text.py`：从模型响应中提取文本、工具调用和 JSON，兼容代码块包裹、模板回显等异常输出。
- `fake_gateway.py`：测试和离线评测使用的确定性模型替身。

## LangGraph 编排

`src/advisor/graph/` 是主流程所在目录：

- `state.py`：会话状态、用户画像、证据、问卷进度、实体注册表和每轮重置字段。
- `builder.py`：注册节点与条件边，并配置 SQLite checkpoint。
- `nodes/supervisor.py`：请求分类、名称解析、指代消解、画像读取和每轮状态清理。
- `nodes/market.py`：行情查询，只取数据，不做投资评价。
- `nodes/research.py`：按股票并行创建研究任务，每只股票再并行执行基本面、技术面和资讯分析。
- `nodes/risk.py`：风险问卷的开始、查询、重做和取消。
- `nodes/advisor.py`：读取证据、记忆和风险约束后生成回答。
- `nodes/auditor.py`：检查免责声明、数字来源、日期边界和指令性表述。
- `nodes/memory.py`：写入持仓、偏好、风险画像和会话结果。
- `nodes/extract.py`：规则抽取及低置信度过滤的 LLM 偏好抽取。
- `nodes/agent.py`：有次数上限的工具调用循环。
- `nodes/text.py`：消息格式适配和面向用户的内容清理。

## 路由与指代消解

`src/advisor/orchestration/` 放置不依赖图状态的辅助逻辑：

- `router.py`：先走低成本规则，无法判断时再调用 router 模型。
- `resolver.py`：使用本地索引把股票名称解析为代码。
- `entities.py`：记录当前会话提到的证券，处理“它”“那只”“走势呢”等指代。

## 工具层

`src/advisor/tools/` 包含 Function Calling 工具和确定性计算：

- `market_tools.py`：行情、K 线、指标、财务、公司概况、估值、指数和公告工具。
- `indicators.py`：MA、RSI、年化波动和最大回撤。
- `risk_model.py`：问卷评分和风险等级映射。

工具失败时返回固定的错误结构，不把异常堆栈直接交给模型。

## 存储与记忆

`src/advisor/store/` 负责长期数据：

- `profile_store.py`：用户画像、持仓、偏好事实、风险历史和审计记录，所有业务数据按 `user_id` 隔离。
- `recall.py`：同义词、子串和关键词召回。
- `embeddings.py`：SiliconFlow 或智谱的 embedding 客户端、余弦相似度计算和 fallback。

LangGraph 的会话 checkpoint 保存在单独的 `data/checkpoints.db` 中。它和长期画像分开，清理会话不会误删用户资料。

## API 服务

`src/advisor/service/app.py` 提供：

- `POST /v1/chat`：调用主图并通过 SSE 返回事件。
- `GET /v1/profile/{user_id}`：读取画像、持仓和记忆。
- `GET /v1/audit`：读取近期审计记录。
- `GET /health`：健康检查。

服务通过 `create_app` 工厂创建，测试时可以传入临时存储和 fake gateway。

## 评测

`src/advisor/evaluation/` 包含固定用例和执行器。`runner.py` 支持 `single`、`fixed`、`supervisor` 三种架构，记录路由、完成情况、免责声明、内容命中、模型调用次数和工具调用次数。逐用例明细可输出为 JSONL，方便定位失败。

`scripts/run_benchmark.py` 是评测入口，支持离线模式、真实模型和单用例复现。

| 文件 | 用途 |
|---|---|
| `scripts/demo_cli.py` | 检查行情和指标链路 |
| `scripts/chat_cli.py` | 命令行对话 |
| `scripts/embed_backfill.py` | 为历史记忆补写向量 |
| `scripts/run_benchmark.py` | 运行架构评测 |
| `scripts/ui_e2e_smoke.py` | 检查网页核心操作链路 |

## 网页

`app/ui/streamlit_app.py` 是单页应用，包含用户选择、风险测评、持仓、画像、聊天和本地数据管理。页面样式和部署按钮配置在 `.streamlit/config.toml`。

## 测试

`tests/` 覆盖数据源、指标、风险评分、模型网关、路由、审计、记忆、主图、API、UI 文本清理和评测。模型与网络路径默认使用 fake gateway，因此常规测试不需要密钥或联网。

主要测试文件：

- `test_graph_p2.py`：主图主要流程。
- `test_p5_memory.py`：画像读取、名称解析和跨重启会话。
- `test_p6_entities.py`：多轮指代消解。
- `test_p8_recall.py`：语义召回。
- `test_auditor.py`：证据、日期和合规检查。
- `test_service.py`：FastAPI 与 SSE。

## 运行产物

- `data/advisor.db`：用户画像、持仓、记忆、风险历史和审计。
- `data/checkpoints.db`：LangGraph 会话状态。

数据库和大部分运行产物不进入 Git。
